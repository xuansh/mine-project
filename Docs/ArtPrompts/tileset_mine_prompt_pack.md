# 矿场 TileMap 素材 · 提示词包

> 和单件素材（[mining_pixel_prompt_pack.md](mining_pixel_prompt_pack.md)）不同，TileMap 的难点不是"画得好"，
> 而是"格子对得齐、边缘拼得上"。prompt 里必须把网格和拼缝写死，否则出来只能当参考图用。

---

## 0. 先定两件事，再谈 prompt

| 决策 | 选项 | 建议 |
| --- | --- | --- |
| 网格类型 | 方形 / 等距 2:1 菱形 | **方形**。等距的 autotile 变体多 4 倍，AI 出图必然对不齐菱形网格 |
| 视角 | 正俯视 90° / 45° 俯视 | 正俯视最好拼；45° 要"顶面 + 侧面"两格叠出立体墙 |
| 瓦片尺寸 | 16px / 32px | 16px 配 640×360；32px 配 1280×720。**32px 更容易让 AI 画清楚** |

> 注意：你现有的 `basic_mini_excavator.png` 是 45° 斜视。如果用方形正俯视瓦片，挖机会"趴"在棋盘格上，
> 视觉上会打架。两个解法：一是瓦片也走 45° 斜视（下面 P6 给了 prompt），二是挖机重画成正俯视。

## 1. TileMap 到底需要哪些图块（漏了这个 prompt 也白写）

| 层 | 内容 | 数量 |
| --- | --- | --- |
| 地面（底层） | 矿土亮、矿土暗、碎石地、岩板地、积水、轨道地 | 6 种 + 每种 3 个随机变体 |
| 岩壁（碰撞层） | 顶面、上/下/左/右侧面、4 个外角、4 个内角 | 12–20 |
| 矿脉 | 铁、金、水晶嵌在岩壁上 | 3 |
| 装饰（无碰撞） | 木支撑、矿灯、碎石堆、铁轨、警告牌、水洼 | 6–8 |
| 危险 | 塌方区、水潭 | 2 |

> 别一上来就要 Godot 的 47 变体 blob autotile，AI 给不了。
> 用 **3×3 最小集**（上下左右 + 4 外角）+ 随机变体打散重复感，视觉上就够用了。

---

## 2. 让 AI 能出 tileset 的 5 条硬约束（必须写进 prompt）

```
① 严格 N 列 × N 行的等大网格，每格尺寸相同
② 每个方格内的图案延伸到该格四条边，相邻格拼接后可无缝重复
③ 统一光照方向（左上），所有图块明暗一致
④ 任何图块的阴影不得投到相邻格子里
⑤ 全图共用一个有限色板，硬边像素，无抗锯齿、无渐变
```

再加一条实操性的：**格与格之间留 4px 纯黑间隙**，出图后在 Godot 里按格切，不会切歪。

## 4. 出图参数与工作流

1. **先出 P0 定调**，再拿 P0 当参考图出 P1–P5，否则 6 张图会像 6 个游戏。
2. **固定 seed**，只改 prompt 里的图块内容。
3. **出大图再缩**：出 2048，缩到 512（8×8 个 64px 格）或 256（16px 格），缩完边缘更脆、像素更统一。
4. **一定会失败的地方**：格子不等大、图案没贴边、格间有阴影。所以——
   - 切图时按"每格 + 4px 间隙"算步长自动切，不要手拉；
   - 切完在 Godot TileSet 里逐块检查四边，缺边的用同色补 1px 再存。
5. **别指望出 47 变体**。就出 3×3，在 Godot 的 Terrain 里配，剩下的靠随机变体打散。

## 5. Godot 落地

- 用 `TileMapLayer`（4.3+），`TileMap` 已废弃。
- `TileSet` 的 tile size 设成出图格子的实际像素（如 64×64），切图用 `TextureRegion`。
- 地形自动拼接用 **Terrain Sets**：地面一组、岩壁一组，用 3×3 最小集配 peering bits。
- 随机变体：同一地形放 3 张变体瓦片，`TileMapLayer` 开 `Rendering > Random Y Sort` 不够，用 `Alternative Tiles` 或自己写脚本按坐标哈希选。
- 导入设置：Nearest 过滤、关 Mipmap、Filter 关。
- 碰撞：在 TileSet 里给岩壁瓦片加 Physics Layer 的矩形/多边形，别用代码手写。
- 效果：叠一层 `CanvasModulate` 压暗 + 一盏 `PointLight2D`（矿灯）+ `LightOccluder2D` 做遮挡，黑暗矿区氛围就出来了，比在贴图里画光更灵活。
