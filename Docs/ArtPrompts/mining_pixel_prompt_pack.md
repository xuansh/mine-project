## 0. 风格怎么"像"参考图，而不是像参考图的题材

参考图的风格其实由 4 条组成，题材随便换都能保持"像"：

| 维度 | 规则 |
| --- | --- |
| 明度 | 底色压到近黑，主体只占画面 20%，其余全黑 |
| 描边 | 1px 近黑硬边，无抗锯齿，无渐变过渡 |
| 饱和度 | 整体低饱和，**全画只留一个高饱和强调色** |
| 光 | 不做体积光，只做"描边 + 一小块高光 + 一点点光锥" |

> 参考图里唯一的暖色是星球。搬到矿区，**唯一强调色就是工程黄 `#D9A227`**（挖掘机警示条、矿灯）。这条守住，风格就成立。

## 5. 尺寸与规格

| 用途 | 出图 | 落地 |
| --- | --- | --- |
| 场景底图 | 1920×1080 | 直接铺 |
| 等距物件 | 1024×1024 | 缩到 128×128（现有挖机 2048×0.05 ≈ 102px，对齐这个数量级） |
| UI 图集 | 1920×1080 | 切图 + NinePatchRect |
| 图标 | 1024×1024 | 缩到 32×32 |

**视角必须写死**：`等距 45 度俯视`，否则模型默认给你正俯视或透视，跟挖机对不上。

## 6. Godot 落地

- `rendering/textures/canvas_textures/default_texture_filter = 0`（Nearest），关 Mipmap。
- 等距素材统一按 2:1 菱形网格切，`Sprite2D` 的 offset 对齐脚底，方便按 y 排序遮挡。
- 矿块换状态：用 `AnimatedSprite2D` 三帧，或用 AtlasTexture 切 `B5` 的三段。
- `MineableEntity` 建议拆成 `Node2D` + `Sprite2D` + `Area2D`，不然 y 排序和点击检测会很别扭（现在它继承 `Node`，贴图挂在子节点上，做不了深度排序）。
- 整体压色用 `CanvasModulate`，别逐张改图。
